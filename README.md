React-клиент для тестового задания Frontend Developer React.

Стек:
- React
- Vite
- CSS
- GREENAPI Telegram API

Для запуска требуется Node.js 18 версии или новее.

1. Необходимо клонировать репозиторий на компьютер, затем прописать в терминале: npm install
2. Для запуска локаьного сервера, пропишите в терминале: npm run dev
3. Открыть адрес, который покажет терминал, обычно это: `http://localhost:5173`.
4. Создайте Telegram instance в GREENAPI по ссылке: `https://console.green-api.com/instanceList`
5. Авторизуйтесь через Telegram.
6. Получите `apiUrl`, `idInstance`, `apiTokenInstance`.
7. В настройках instance включите входящие уведомления и уведомления об исходящих сообщениях.
8. В приложении введите эти данные.

ВАЖНО: В текущем варианте токен не сохраняется в состоянии, поэтому обновляйте страницу с осторожностью.

В приложении реализовано:
- проверка состояния instance;
- получение списка Telegram-чатов;
- создание нового чата по номеру телефона;
- загрузка истории выбранного чата;
- отправка текстовых сообщений;
- получение новых сообщений;
- удаление обработанных уведомлений;
- простой адаптивный UI.
